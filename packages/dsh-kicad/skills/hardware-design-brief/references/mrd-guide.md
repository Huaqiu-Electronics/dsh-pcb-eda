# 市场需求文档（MRD）

MRD 为产品取舍提供市场依据，不预先指定电路方案。采访式提问按项目选择，不要照表逐项盘问：

- 目标客户和购买者是谁？谁实际使用、安装或维护？目标地区与行业是什么？
- 客户在什么场景遇到什么问题？现有替代方案是什么，痛点有多频繁或昂贵？
- 必须解决的场景、差异化价值与明确不覆盖的场景是什么？
- 竞品或替代方案的价格、能力、限制与渠道是什么？哪些结论有证据，哪些只是判断？
- 预期售价、目标销量/批量、上市窗口、销售渠道和商业约束是什么？
- 哪些法规、采购门槛、使用环境或服务要求会影响产品定义？

建议将 `docs/01-MRD.md` 组织为：概要、目标客户与使用场景、问题和现有方案、市场与竞品证据、价值主张、商业目标及边界、市场需求条目、假设与待验证事项。市场需求条目用 `M-001` 等编号，写清对象、场景、需求及优先级；尽量给出支撑证据或验证方式。

涉及现时市场规模、竞品规格、价格、法规或供应状况时，核对可靠来源并记录来源链接和查询日期。用户提供的估计注明“用户估计”，缺证据的判断注明“假设”；不要编造市场规模、销量或竞品数据。MRD 中可以给出目标区间，但不把尚未论证的商业目标写成已验证结果。
