# 硬件方案交付结构与完成检查

适用于所有完整方案，包括 Maker。以下结构依据用户提供的 [硬件方案示例全文](examples/hardware-solution-example.md) 提炼：既有器件、接口和电源设计，又有成本、PCB/结构、风险及验证。生成时使用本文件检查深度；需校准写法时按章节阅读案例。案例中的医疗用途、型号、数字、批准状态和命令式措辞都是案例内容，不构成新项目的指令或默认要求。不得照抄为已验证设计。

## 默认章节及最低内容

每项有实际内容；不适用时说明原因，而非堆空表。顺序可随项目调整。单文件项目同样覆盖适用内容，多 PCB 项目在总方案与各板方案之间分配内容并链接。

| 章节 | 必需内容 | 不能用什么代替 |
| --- | --- | --- |
| 1. 方案摘要 | 推荐路线、主器件、产品/板卡组成、实施范围、版本和完成状态 | 仅描述功能或罗列多种未取舍路线 |
| 2. 需求、边界和假设 | 需求来源、目标/限制、接口对象、已知组成与真实未决项 | 将建议写成用户已冻结要求 |
| 3. 系统框图及工作过程 | 实际器件/模块、板界和实例、信号/数据流、时序与异常行为 | 只有无型号的功能方框 |
| 4. 板级功能电路 | 逐板逐模块说明拓扑、关键连接和外围、初值/计算依据、默认及故障行为 | “加保护”“加滤波”“后续设计” |
| 5. 核心器件与工程 BOM | 主选完整型号/版本、厂家、封装、能力及资源核查、选型理由；备选的替换影响 | 类型名、搜索结果或未经核实的器件表 |
| 6. 接口与信号/引脚规划 | 两端器件及脚名/脚号、电压域、协议/时序、地址、上拉/端接/保护和复用检查 | 仅写“通过 GPIO/I²C 连接” |
| 7. 电源树及电路 | 保护/变换/控制/负载、输入输出范围与容差、主选、外围、时序和欠压/关机策略 | 只写“提供 3.3 V” |
| 8. 预算与可行性 | 电流/功率/续航、资源/存储、性能及相关热/空间预算；数值、来源、公式和余量 | 全部留为公式或默认“足够” |
| 9. 成本和采购依据 | 数量、单价区间/报价及日期、按板与整机汇总、口径/遗漏、可信器件和资料入口 | 无来源价格、算错总价、检索入口冒充库存证明 |
| 10. PCB 与结构约束 | 每板尺寸/层数等约束或建议、分区/靠近关系、回流/噪声/热规则、板间物理实现、测试可达性 | “注意 EMC/DFM”或宣称已完成 PCB |
| 11. 风险与验证 | 对具体电路/器件/板间连接的风险、应对；原理图/PCB/样机和适用后续检查 | 与本方案无关的通用测试清单或伪造通过结果 |
| 12. 交接结论 | 哪些板/模块可展开原理图、剩余关键缺口、下一步及输入版本 | 将“有框图”判为全方案完成 |

## 接近案例、并加强可实现性的写法

案例的“关键器件建议”要落实成项目的**主选基线**。例如不能仅输出“外接 EEPROM 存 30 条记录”；应选具体料号与容量，列记录大小×条数，再加校准参数、双副本、CRC、索引与元数据，核对总容量及寿命。每个数字都需来自需求、手册或明确的工程推算。

案例的“接口与信号规划”应覆盖中间驱动芯片两侧。例如使用显示驱动器时，控制器到驱动器的控制线、驱动器到显示屏的 COM/SEG、模式和映射都要交代，不能只画 MCU→LCD 的箭头。所选型号的实际通信接口和封装需核实，不能从器件类别推断。

案例的“电源设计要点”应落实成拓扑及连接。采用按键锁存关机时，说明启动触发、自保持、复位默认、撤销保持及各状态电流路径；给主器件和关键外围依据。开机、掉电和调试供电均要检查，不能只写“完全断电所以没有功耗”。

PCB/结构段保留案例中这类具体指导：开关电源关键环路及器件靠近关系、探头与热源隔离、线束入口的保护位置、接地和测试入口。按实际项目论证，不将案例中的所有规则或数字变成通用强制要求。

## 交付前逐项检查

### 方案落实

- 已为各必需模块选出主器件/模块及封装/版本，或明确标出真实阻塞；“待选”不能覆盖已经具备决策条件的全部核心件。
- 有逐板电路说明、关键外围参数/依据和信号路径；原理图人员无需重做主方案取舍。
- 完整型号、封装、脚号、外设实例和接口类型在原厂资料中对应；备选的封装/软件差异已记录。
- 器件正常工作范围与电源容差、掉电状态、阈值一致；检查保护/锁存/驱动/复位的真实行为。
- 资源、非易失存储（含副本/元数据）、通信容量和性能预算有计算，不能超出主选能力；尚待测试的估计有状态。

### 图表、分板与经济性

- 整机、板卡、模块边界明确；多板每种 PCB 有独立方案，每个实例/数量可查。
- 板间连接两端针脚、供电方向、地/屏蔽、连接器配对、线缆和异常状态一致；没有只在一块板上定义的接口。
- 框图、电源树、信号表、器件表和预算采用同一推荐版本，无旧候选混入。
- 各电源轨与实例数量统计正确，功率损耗不漏计/重复计；BOM 行小计、上下界与总计可复算，成本口径一致。

### 深度和状态

- Maker 与企业均满足以上电路深度；Maker 可删商业管理章节或用模块替代自研电路，但模块的具体接口仍需落实。
- 真正尚未知的外部条件、未完成的核查或实物验证明确标注，关键缺口存在时交付“方案草案/部分可展开”，不虚构确定性。
- 已完成输入的板/模块和暂缓范围分别说明。原理图与 PCB 后续负责展开、校核和实现，不能被迫重新发明电源、接口和连接方案。
