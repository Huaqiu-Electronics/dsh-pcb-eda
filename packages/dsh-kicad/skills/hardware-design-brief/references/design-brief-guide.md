# 原理图与 PCB 设计输入

本文件将已确认的产品需求转成开工约束，保持简练。先从 PRD 和已有设计资料提取信息，再追问会影响电路架构和 PCB 实现的事项：

- 电源输入、各电源轨、电流/功率预算、负载、时序和保护。
- 核心器件及所需计算、存储、外设、封装、供货和软件/工具链条件。
- 有线/无线接口、连接器、电平、速率、线缆长度、隔离、调试与测试接口。
- 板外形、板厚、安装孔、禁布区、器件高度、连接器位置和方向。
- 层数、叠层、铜厚、阻抗、高速/模拟/大电流/天线区域、散热和 EMI 约束。
- 制造、装配、检测、维修、环境及适用标准的设计输入。

建议将 `docs/03-design-brief.md` 组织为：项目目标与适用 PRD 编号、原理图设计要求、PCB 设计要求、关键器件表、待确认与验证。原理图部分说明功能分区、核心器件、电源、接口、保护和测试点；PCB 部分说明尺寸、层数、机械、布局与工艺约束。每项关键设计要求引用相关 `H-` 编号；若是工程建议而非 PRD 硬性约束，标明“建议”。

区分**指定器件**、**候选器件**和**待选**。具体候选需有足够的功能、电气、封装和供应信息支撑，并说明选择依据与待核实项；未经核对的候选不可写成批准选型。PCB 尺寸、层数、板厚、铜厚和阻抗优先记录明确边界；若用户需要建议，可基于密度、速率、阻抗、电流、散热、EMI、成本及制造能力提出建议值。未知参数写“待确认”，不虚构精度。

对安规、EMC、热、信号完整性及可制造性，列明需要计算、仿真、打样或测试的验证事项。design brief 是设计输入，不代表这些项目已经满足要求。
