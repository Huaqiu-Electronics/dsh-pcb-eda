# 阶段边界：先完成电路方案，再展开详细设计

硬件方案是原理图及 PCB 的主要依据。本阶段不直接绘制完整 EDA 文件，不代表核心选型、接口电路、关键参数及模块连接也应后置。先保证后续工程师能依据文档实现，不必重新做主要方案决策。

## 同一话题在各阶段的深度

| 话题 | PRD：要求与分配 | 硬件方案：应完成的设计输入 | 原理图/PCB/制造：后续落实 |
| --- | --- | --- | --- |
| 产品与多板 | 整机边界、已有板卡组成、各板职责和要求；未知分板标提案 | 确定 PCB 类型/数量/实例、板级方案、板间接口和供电，回填 PRD | 每板独立设计文件、版本与整机装配配置 |
| 核心器件 | 性能、成本、环境及用户指定约束 | 厂家、完整型号/版本、封装、主选依据、兼容性与资源核查 | 建库、全引脚接线、全量物料核验和采购放行 |
| 电源/保护/驱动 | 输入、负载、功耗、异常行为 | 具体拓扑、器件、关键外围/初值、使能/复位/锁存、阈值及预算依据 | 完整电路、全部阻容位号、仿真/实测调优；验证不后移方案必需计算 |
| 信号与引脚 | 协议/速率/电气条件、兼容对象 | 核心信号逐项连接、外设实例及引脚映射、地址/上下拉/端接/隔离、默认及故障状态 | 补齐非关键接线、ERC/网络核验、由实现调整并回写基线 |
| 板间互连 | 两端职责、安装/线缆和供电要求 | 连接器配对型号、针序/映射、线缆/FPC、地/屏蔽、功率和保护、插拔与顺序 | 完整线束图、机械装配图、详细应力及工艺确认 |
| PCB 与结构 | 固定机壳、接口位置、包络及制造能力 | 板尺寸/层数/板厚的约束或建议、功能分区、热/回流/噪声布局规则及阻抗等目标 | 最终叠层及制造参数、求解线宽/间距/等长、精确布局布线、Gerber |
| 装配与测试 | 数量、手焊/外协、维修/校准目标 | 可焊封装、接口可达性、烧录/测试信号与连接、定制件配合和关键装配约束 | 全部测试点坐标、治具结构、钢网、拼板、回流工艺和工艺卡 |
| 安全与合规 | 地区、用途、环境及适用目标 | 核实影响设计的适用条件，完成隔离/保护方案和所需设计目标，未决项列动作 | 详细规则验证、专项试验及正式合规证据 |
| 物料与成本 | 预算与批量口径 | 核心器件清单/工程 BOM、主要外围与成本估算、采购核实状态 | 带全部位号、封装的完整 BOM 和生产放行 |

## 如何处理尚未确定的参数

- **用户或既有产品的硬约束**：原样继承并查冲突，不因“属于后期”删除。
- **可由手册和计算决定**：本阶段给推荐值/范围、依据和适用条件，例如分压、上拉、滤波、反馈、限流；不要一概写待定。
- **需布局或试验收敛**：本阶段先给目标、初值/范围和验证方法，后续调优并回写方案。
- **缺少会改变路线的外部条件**：只阻塞受影响模块，可交付条件化草案；核心电路未闭合时不能宣称整板方案完成。

例如手焊项目需要本阶段选能焊的封装；高速接口需要先有主选器件、连接和布线目标；固定外壳项目需要落实可用包络与连接器方向。不能在方案期仅说“后续考虑”，也不能将尚无依据的参数写成冻结结论。

## 交接含义

“可进入原理图”意味着主选器件与封装、电源/接口/关键外围、引脚资源、板间连接和约束已足以展开电路。可以有不影响路线的细节待优化，但不能留下迫使绘图人员重新选主控、供电或接口的关键空白。

“可用于 PCB 设计”意味着方案已给 PCB 约束和设计目标；实际布局布线还依赖完成的原理图、封装与机械协调。“可投板/装配”则需要后续设计检查与制造数据。三者不能混用。
