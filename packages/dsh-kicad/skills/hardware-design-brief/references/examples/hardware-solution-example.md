# 方案摘要

面向6个月及以上儿童和成人的家用智能耳温枪，采用“数字式红外耳温探头模组＋低功耗国产MCU＋定制段码LCD＋两节AAA电池”架构。主板通过I²C读取探头原始温度/环境数据，结合整机多点黑体校准参数完成补偿。耳套为一次性必需耗材，采用机械在位检测并阻止未装耳套测量。整机以低成本、可追溯校准、低待机功耗和量产可制造性为核心。

# 需求与假设

## 已确认需求要点

1. 测量对象为耳温，首版适用人群为6个月及以上儿童和成人。
2. 测量输出范围冻结为34.0～42.0℃，显示分辨率0.1℃。
3. 使用环境冻结为：
   - 环境温度：15～40℃
   - 相对湿度：≤85%，无凝露
   - 气压：70～106kPa
4. 黑体实验室误差设计目标：全输出范围、全环境边界下≤±0.2℃。
5. 按下测量键至结果显示目标≤2秒；环境未稳定或测量无效时不得输出伪正常结果。
6. 保存最近30次有效测温结果；掉电后保留；超出后覆盖最旧记录。
7. 高温采用固定阈值`T_alert`，由医学/法规评审后写入受控配置区。
8. 采用两枚AAA碱性电池，正常工作输入范围按2.0～3.2V设计。
9. 30秒无操作自动关机；目标续航≥180天，按每天10次、每次通电30秒、背光≤5秒计算。
10. 耳套为每次测量必需耗材，必须具有耳套在位检测，未装耳套时禁止测量。
11. 采用定制段码LCD，显示温度、记忆标识、电量、错误码、高温图标及必要状态图标。
12. 每台整机实施多点黑体校准，校准参数采用CRC保护并与序列号绑定。
13. 首批1,000台的经常性制造成本目标小于70元/台，内部设计分配目标为60元/台。
14. 按国内第二类医用红外耳温计注册路径设计，需支持软件、EMC、安全、家庭使用及可追溯要求。

## 工程假设

1. 数字探头不直接采用通用“额温枪模组”，而是采用带金属探头壳、视场控制、热隔离结构及可输出原始温度数据的耳温专用数字探头组件。
2. 探头核心传感器优先采用MLX90632系列；该器件为数字红外温度传感器，但最终精度取决于探头光学、热设计、耳套透过特性、算法及整机校准，不能仅依赖芯片标称精度。
3. 主板采用国产低成本MCU，传感器、LCD驱动器及非易失存储器均使用I²C或GPIO连接。
4. 整机采用“完全断电式自动关机”架构，非工作状态仅保留机械按键唤醒路径，避免长期待机电流影响180天续航。
5. 定制LCD采用常温工作液晶玻璃，建议工作温度覆盖0～50℃；储运、跌落、清洁及防护等级由法规/质量团队冻结后进入DVT验证。
6. PCB按两层板量产设计；若探头模拟前端、无线连接或复杂背光方案后续增加，则重新评估四层板。
7. 工厂使用弹簧针治具完成烧录、序列号写入、黑体校准参数写入、功能测试和追溯记录绑定。

## 数据流说明

1. 用户安装耳套后，耳套在位检测开关导通，允许进入测量流程。
2. 按键启动电源锁存，MCU上电后读取探头状态、环境温度、电池电压及耳套状态。
3. MCU通过I²C读取数字探头的红外温度、环境温度及状态数据。
4. 固件执行探头稳定性判断、耳套在位判断、环境补偿、整机校准参数补偿及异常检测。
5. 有效结果显示于段码LCD；若超过`T_alert`，显示高温图标并播放区别于完成音的提示音。
6. 有效读数及状态标记写入EEPROM环形存储区；无效读数、故障读数不得写入新历史记录。
7. 30秒无操作后，MCU撤销电源保持信号，整机完全断电。

# 电源树与功耗预算

## 电源架构

```text
两节AAA电池（2.0～3.2V）
          │
          ├── PTC/反接保护/电源锁存MOSFET
          │
          └── 升压DCDC（标称3.3V，允许3.0～3.3V）
                    │
                    ├── 数字耳温探头
                    ├── MCU
                    ├── EEPROM
                    ├── LCD驱动器及LCD
                    ├── 蜂鸣器驱动
                    └── 背光LED驱动
```

## 电源设计要点

1. **完全断电自动关机**  
   30秒无操作后MCU关闭保持MOSFET，DCDC及数字电路全部断电。这样可将静态损耗降至电池漏电和MOSFET漏电等级。

2. **按键开机保持**  
   测量键按下时直接触发电源锁存；MCU启动完成后通过GPIO拉住保持信号。发生程序异常或低电压复位后，保持信号自动释放，避免死机持续耗电。

3. **低电压策略**  
   建议将低电量提示阈值、禁止测量阈值分开处理：
   - 低电量提示：建议电池组约2.25～2.40V，最终由续航和精度试验冻结；
   - 禁止新测量并提示更换电池：建议电池组约2.05～2.20V；
   - 禁止阈值下不得写入校准参数，不得输出未经验证的有效温度结果。

4. **DCDC选择原则**  
   升压芯片必须满足2.0V输入时的冷启动、探头启动、LCD背光及蜂鸣器同时工作要求。若替代为低成本升压芯片，必须在电池低压、低温和满载情况下重新验证输出纹波及启动可靠性。

# PCB 与结构约束

## PCB层数及尺寸建议

1. 建议采用**双层FR-4 PCB**，板厚1.0～1.2mm。
2. 主板建议布置于手柄区域，避免靠近探头前端。
3. PCB外形应配合电池仓、LCD窗口、按键胶帽及蜂鸣器声孔设计；主板不应成为探头热量传导路径。
4. 探头建议采用独立FPC或柔性线束连接主板，线束长度建议控制在80～180mm范围内，并通过结构卡扣固定防止拉扯。

## 关键布局约束

1. **探头热隔离**
   - 红外传感器及探头壳必须与主板、电池、DCDC电感、背光LED及蜂鸣器热源隔离。
   - 探头内部优先使用低导热支撑结构，并避免探头壳直接与主板大面积铜箔、螺钉柱或电池仓硬连接。
   - 探头线束不应与背光LED、电感及蜂鸣器驱动线长距离平行。

2. **DCDC布局**
   - TPS61023、电感、输入电容、输出电容构成最小电流环路。
   - 电感及开关节点远离探头接口、I²C走线、LCD斑马条区域和MCU复位线。
   - 开关节点铜箔面积应尽可能小，避免形成辐射源。

3. **数字探头I²C布局**
   - 探头I²C接口附近设置ESD器件及串联阻尼电阻。
   - I²C走线优先靠近地参考，避免跨越DCDC开关节点。
   - 探头线束屏蔽层如存在，应单端或按探头供应商建议与系统地连接，避免形成不受控环路。

4. **LCD布局**
   - LCD玻璃与主板采用斑马条时，接触焊盘应镀金或采用可靠表面处理。
   - LCD COM/SEG走线应避免过孔、避免与高电流线平行，防止显示串扰和EMI耦合。
   - 背光LED热量和光线应通过导光件控制，不得直射探头内部。

5. **EEPROM和校准安全**
   - EEPROM应靠近MCU放置，I²C走线短且具有完整地参考。
   - 校准区与历史区采用不同逻辑地址区，固件须分别进行CRC校验。
   - 生产后关闭或锁定调试访问策略，工厂模式进入条件应采用硬件治具识别或加密挑战机制。

## EMC与抗扰注意事项

1. 电池入口配置反接保护、ESD保护及必要的瞬态抑制措施。
2. 探头线束是潜在ESD和辐射耦合路径，连接器/FPC入口必须配置ESD器件。
3. 电源地、数字地、DCDC回流地采用完整地平面连接，避免将探头信号回流穿越DCDC区域。
4. 蜂鸣器驱动、背光PWM和DCDC开关频率应避开探头采样及I²C通信关键窗口；测量采样期间可关闭背光PWM或固定其状态。
5. PCB预留RC滤波、串联电阻、ESD器件和地弹簧测试位，便于EMC整改。
6. 外壳探头金属件若可接触，应由法规及安全团队确认其接地、隔离及ESD泄放策略。
7. 结构设计应确保耳套装卸、清洁液残留、汗液或冷凝水不会沿探头缝隙进入传感器窗口或主板区域。

# 验证计划

## 1. 原理图审查阶段

1. 确认电源锁存逻辑：
   - 按键可可靠开机；
   - MCU可维持供电；
   - 超时、复位、低电压及程序异常后可自动关机；
   - 电池反装时无器件损坏及异常发热。

2. 确认电源输入范围：
   - 电池输入2.0～3.2V；
   - DCDC在2.0V输入下可稳定启动；
   - 背光、蜂鸣器、探头并发时系统电压不低于器件工作下限。

3. 审查探头接口：
   - I²C地址、时序、电平及上拉电阻满足探头要求；
   - 探头接口具备ESD和串联阻尼；
   - 探头断线、短路、I²C无应答时可被固件识别。

4. 审查存储与校准安全：
   - EEPROM地址分区明确；
   - 校准参数、设备序列号、软件版本、历史数据逻辑隔离；
   - CRC、双备份、掉电写保护及工厂写入流程可实现。

5. 审查耳套检测：
   - 默认状态为“未装耳套”；
   - 开关断线、开路、接触不良均不允许测量；
   - 输入端具备硬件/软件消抖。

6. 审查工厂测试点：
   - 预留SWIO、GND、VBAT、3V3、I²C及关键GPIO测试点；
   - 测试点位置满足弹簧针治具接触和结构避空要求。

## 2. PCB审查阶段

1. 检查DCDC高di/dt回路是否最小化，电感、输入电容、输出电容及芯片布局是否紧凑。
2. 检查DCDC开关节点是否远离探头接口、LCD、MCU复位线和EEPROM。
3. 检查探头FPC/线束连接器附近是否已布置ESD器件。
4. 检查探头信号走线是否具有连续地参考，是否避免跨分割地。
5. 检查LCD COM/SEG焊盘、斑马条压接区和背光LED导光结构的装配空间。
6. 检查电池弹片、电池盖、主板螺钉柱与PCB铜箔之间的绝缘距离。
7. 检查蜂鸣器声孔、背光导光柱、按键胶帽及耳套检测机构与PCB器件的干涉关系。
8. 检查测试点可达性，确认外壳装配前后工厂治具均可完成必要测试。

## 3. EV板测试

### 基础功能测试

1. 上电、关机、30秒自动关机、按键唤醒及低电压关机测试。
2. 探头I²C通信、传感器ID读取、异常状态读取及通信重试测试。
3. LCD全段点亮、全图标点亮、温度显示、记忆显示、电量显示及错误码显示测试。
4. 蜂鸣器完成音、高温音、故障音区分测试。
5. 背光亮度、点亮时长、PWM噪声及对测温稳定性的影响测试。
6. 耳套在位、未装套、半装套、开关断线及反复装卸测试。
7. 30条历史记录循环覆盖、掉电恢复、无效读数不写入测试。
8. 校准参数CRC错误、EEPROM读写失败、传感器故障、低电压、超范围等故障注入测试。

### 初步计量与热设计测试

1. 在25℃环境下，对34.0～42.0℃黑体点进行初始误差测试。
2. 对同一黑体连续测量不少于20次，评估短期重复性。
3. 测试开机后不同时间点的结果变化，确定探头稳定时间及算法等待条件。
4. 测试背光开启、蜂鸣器工作、连续测量、手持状态、电池发热状态下的温漂。
5. 对未装耳套、不同耳套批次、耳套装配深度偏差进行测量偏差评估。
6. 初步验证按下测量键至结果显示是否可达到≤2秒目标。

## 4. DVT测试

### 性能验证

1. 按15℃、25℃、40℃环境温度进行黑体矩阵验证。
2. 黑体覆盖34.0、35.0、36.0、37.0、38.0、39.0、40.0、41.0、42.0℃或法规确认的正式校准点。
3. 每个环境及黑体点覆盖多台样机、多批次探头、多批次耳套。
4. 评估误差、重复性、再现性、环境漂移、耳套批间差异及扩展不确定度。
5. 验证低电压边界、满电边界、连续测量边界及环境突变后的等待/错误策略。
6. 验证高温阈值`T_alert`上下边界、高温图标及提示音逻辑。

### 可靠性与结构验证

1. 按法规/质量冻结的跌落高度、次数、方向及跌落后功能要求测试。
2. 按冻结的清洁剂、擦拭次数及耳套更换次数进行材料和功能验证。
3. 验证耳套安装力、拔出力、定位深度、探头配合、防脱落及耳道安全性。
4. 验证电池盖寿命、电池反装、跌落后电池接触可靠性及低温启动能力。
5. 验证LCD显示完整性、背光寿命、按键寿命及蜂鸣器声压稳定性。
6. 按冻结的贮运温湿度条件进行高低温贮存、运输振动及恢复测试。

### 安全、EMC与量产验证

1. 按法规适用标准开展静电放电、辐射骚扰、传导抗扰度及电快速瞬变等EMC预扫描和整改。
2. 验证ESD作用于探头、按键、LCD窗口、电池盖及外壳缝隙时不会产生错误有效读数。
3. 建立工厂烧录、序列号绑定、黑体校准、CRC校验、成品测试及追溯记录流程。
4. 验证校准工装的黑体稳定性、定位重复性、测试节拍、参数写入一致性及异常拦截能力。
5. 试产阶段统计探头偏差分布、耳套偏差分布、校准良率、返工率及单位校准工时，确认经常性制造成本满足70元/台目标。
