# 常见情况

| 情况 | 处理 |
| --- | --- |
| 无铜区，只说“重新填充” | 说明没有可填充对象；不要自行新建双面 GND。 |
| 已有同网络同层铜区 | 读取边界确认是否满足范围，优先复用；部分覆盖不能声称整板已铺。 |
| 不同网络或相互重叠铜区 | 保留已有优先级和连接设置；无法读取关键设置时停止修改，不自动覆盖。 |
| AGND、DGND、PGND 等多个地网 | 使用用户指定的精确网名，不自动合并、桥接或跨区域铺铜。 |
| 双层或多层板 | 先确认目标层，不因为层存在就全部铺；未启用层不能作为目标。 |
| 矩形闭合板框 | 使用实际边界和已确认范围；工具默认值不等于已实现设计规则或边缘内缩。 |
| 凹形、圆弧、内部挖空、多个独立外框 | 不使用包围盒猜边界；现有 points 工具不能直接表达孔洞和圆弧，须有已验证原生能力或用户明确的可表达范围。 |
| 高频、天线、隔离槽、爬电间距 | 保留禁布与特殊设计要求；不能从几何空白推断允许铺铜。缺失设计意图时询问。 |
| 重复执行或某层已创建后失败 | 按本次返回 UUID 重新读取，确认已有对象后继续；不重复新建，不删除用户原铜。 |
| 全板填充影响已有其他区域 | 明确 refill 工具作用于全板已有区域；只授权局部填充而接口不支持时说明限制。 |
| 填充成功但仍有未连接或孤岛 | 只报告实际检查结果；填充完成不证明电气设计合格，不能凭视觉作结论。 |
| 超时、取消或编辑器关闭 | 先确认写入结果，报告已知与未知；不盲目重试写入，不自动保存。 |

工具不能设置热焊盘、连接方式、间距、优先级或孔洞时，不能在回复中承诺这些参数已采用。确有此要求时，应复用已验证的公开 KiCad IPC 能力，或明确报告能力缺口；不修改 PCB 文件文本补救。
