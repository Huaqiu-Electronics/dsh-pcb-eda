# 布局质量审计（P4b · 数值 half）

union 外接矩形 / 页面面积 **不能** 代表「页面是否紧凑」。Agent 在 P4b 应运行 `template/scripts/layout-audit.ts` 或等价逻辑，并据结果 **改 P1 坐标或 P4a 框**，而不是口头估计「约占 78%」。

**与 PDF 整页导出配套**：本脚本负责 **可算指标**；`export-layout-pdf.ts`（先 `saveProject`）负责 **整页矢量目视**（模块分区、标题是否在框上、空白是否刺眼、页尺寸是否过大）。模块化验收 = **layout-audit → save → export PDF →（可选）vision 读 PDF 路径**。

## 推荐指标

阈值为 **起始经验值**（与 `layout-audit.ts` 内常量一致），可按项目调整；但 ❌ 项应始终为 0。

| 指标 | 含义 | 参考阈值 |
| --- | --- | --- |
| **导线穿模块框** ❌ | 导线段与任一模块框边界相交 | **0** —— 跨模块只走双端 stub+alias |
| **空框** ❌ | 框内无器件 | **0** —— 删掉或重算 union |
| **内容净距** ❌ | 框边到最近器件 | **≥ 20 ext**（`MIN_CONTENT_CLEARANCE`） |
| **单模块密度** | 框内 20 ext 网格占用率 | **35%～70%**：过低→合并/并排；过高→扩框/拆分。≤ 4 个器件的小模块只提示不判下限 |
| **六分区占用** | 页面 2×3 分块的 50 ext 网格占用 | **≤ 72%**，超出考虑拆模块或加页 |
| **最大空白矩形** | 页面内最大无内容轴对齐矩形 | 占页面 **≤ 10%** |
| **页边距均衡** | 左/上/右/下（内容 union 到 page_box） | **max/min ≤ 2** |
| **最近邻框间距** | 每个框到最近模块框的净距 | **60～120 ext**；> 180 视为「各飞一方」 |
| **网格对齐** ❌ | 每条框边要么贴整体外轮廓，要么与另一框同边对齐，要么与相邻框隔一个走廊 | 不满足的框 **0** |
| **相邻框间距统一** ❌ | 上下左右直接相邻的框之间的净距 | 极差 **≤ 20 ext**（目标都是 `LABEL_CORRIDOR` 60） |
| **框边吸附** | 框边 mod 20 | 全部 **0** |
| 真实填充率 | Σ 器件 bbox / 页面 | 参考量，**不**作为紧凑度结论 |
| union 占页比 | 内容外接矩形 / 页面 | 参考量，**禁止**单独用它声称「已够满」 |

## 反面模式（禁止）

1. **固定大页 + 固定大槽** — 如默认 1800×1400 配 500×400 槽 → 模块必然相距过远。应 `planCompactZones` 按模块清单反推（见 `modular-layout-compact.md`）。
2. **整页 magic 坐标** — P1 写死 x/y，P4a 只能逐模块手调 pad → 框永远不对齐。
3. **非网格 margin** — 如统一 pad 36 ext，36 不是 20 的倍数。
4. **跨模块拉长导线** — 应双端 `placeShortStubAlias`（stub ≤ 40 ext）；否则导线穿框、版面变乱，长 stub 还会跨走廊抓邻居并网。
5. **用 union 占比声称「已够满」** — union 只包住最远器件，中间大块空白仍可能存在。
6. **P4a 先于 P3** — 框与布线互相牵制，应器件+线稳定后再画框。
7. **外围模块平铺成一长行** — 行高被主控撑高，上下大片空白。应按列堆叠（`col` / `order`），小模块同层并排（`group`）。
8. **先接跨模块标签再收拢** — 收拢把模块挤到 60 ext 走廊，先挂的 stub 会越框抓到隔壁模块。顺序必须是 P3 → P3.5 → P3c。
9. **框各自紧包内容** — 每个框大小不一、顶底不齐，像散落的盒子。整页模块化用 `placeGridFrames` 按网格单元拉齐。
10. **移动模块只搬器件** — 导线、电源符号、NetAlias 是独立对象，只搬器件会拖歪导线（并网）、留下符号和标签（掉网）。整页收拢只用 `repackModules`（按电气连通收集），不要自己拿器件 id 调 `moveExtBatch`。
11. **用 `page_box.max.y` 当 `PAGE_TOP`** — page_box 被归一化，与画布原始 y 差一个页高；按它摆的符号/母线落到别的网络旁边，一次把 GND、NRST 并进 +3V3。用 `calibratePageTop`。

## 修正策略（按优先级）

1. **导线穿框 / 空框 / 内容贴框**：先修这三类 —— 改 alias、删空框、重跑 `placeGridFrames`。
2. **网格对齐 / 间距不统一**：确认跑过 `repackModules`；框由 `placeGridFrames` 画；没有手写坐标。
3. **模块过空（< 35%）**：`placeGridFrames` 已退回紧框的模块 → 与同列小模块 **合并**（晶振+负载、复位+按键、SWD+BOOT）、改成 **并排**（同 `group`），或换到更矮的列。
4. **整页空白 / 页边距失衡**：通常是跳过了 P3.5；重跑 `repackModules`。
5. **分区过挤（> 72%）** 或模块密度 > 70%：拆分模块或略放大该模块 `w`/`h` 后重跑 P3.5。

## 脚本

```bash
cd template && npx tsx scripts/layout-audit.ts
# 可选：FRAME_RECTS=id1,id2,...（默认用 listPageDecorations 自动发现模块框）
```

输出：页面与页边距、整页空白地图与最大空白矩形、六分区占用、每个模块框的密度/净距/mod20、最近邻间距散度、**网格对齐与相邻间距**、**导线穿框**统计，最后给出「结论」与建议动作。
