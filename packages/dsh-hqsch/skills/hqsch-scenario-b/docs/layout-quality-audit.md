# 布局质量审计（P4b 目视前必跑）

union 外接矩形 / 页面面积 **不能** 代表「页面是否紧凑」。Agent 在 P4b 应运行 `template/scripts/layout-audit.ts` 或等价逻辑，并据结果 **改 P1 坐标或 P4a 框**，而不是口头估计「约占 78%」。

## 推荐指标

| 指标 | 含义 | 参考阈值 |
| --- | --- | --- |
| **真实填充率** | Σ 器件 bbox 面积 / 页面面积 | 随电路而定；最小系统通常 2–8% |
| **union 内部填充** | Σ 器件面积 / 内容 union 面积 | 过低说明 union 内大片空白 |
| **网格占用率** | 有器件的 N×N ext 格 / 总格 | 50 ext 格：约 25–45% 为合理 band |
| **最大空白矩形** | 页面内最大无内容轴对齐矩形 | 占页面 **< 10%** 较理想 |
| **页边距均衡** | 左/上/右/下（框或器件 union 到 page_box） | max−min 边距 **< 2×**；避免贴底（下 < 40 ext） |
| **模块间距散度** | 框两两最近间距 max/min | **< 5**；过大说明模块「各飞一方」 |
| **网格对齐** | 框边 mod 20（或 mod 50） | **7/7 模块框** 应为 0 |

## 反面模式（禁止）

1. **整页 magic 坐标** — P1 写死 x/y，P4a 只能逐模块手调 pad → 框永远不对齐。
2. **非网格 margin** — 如统一 pad 36 ext，36 不是 20 的倍数。
3. **用 union 占比声称「已够满」** — union 只包住最远器件，中间 750×750 空白仍可能存在。
4. **P4a 先于 P3** — 框与布线互相牵制，应器件+线稳定后再画框。

## 修正策略

1. **P1**：先划 **槽位网格**（列×行，cell 400×300 ext 等），模块占 1–2 格，器件坐标 = 槽位 origin + 网格内偏移（20 的倍数）。
2. **P4a**：框 = 槽位矩形 ± 固定 40 ext（40 是 20 的倍数）；标题 y = 框 y1 − 24。
3. **居中**：`offset = (pageW - contentW) / 2` 整体平移各槽位（仍保持网格）。
4. **P4c**：仅当 P0 估页明显偏大且 orphan 线已清理。

## 脚本

```bash
cd template && npx tsx scripts/layout-audit.ts
```

输出：union 比、真实填充率、50 ext 空白地图、框 mod20、模块间距、最大空白矩形。
