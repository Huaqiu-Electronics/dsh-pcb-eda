# 布局验收与交付

主 agent 首次验收前读一次。子 agent 的基本要求由 task.md 提供；只有具体布局问题才定向查本页。

## 布局准备

新画电路按输入→处理→输出安排，去耦、复位和启动支路靠所属引脚，电源/地、长型号、位号和标签均预留空间；GND默认向下，实际方向由符号和拓扑决定。复用模块已有清楚布局时保留。

子 agent 写首版前先读任务所附的本模块参考说明及参考图，再用 draw 接口和实际几何自行编写。只读选定项；代码仅在确需复用时读取。主 agent补选参见 [画法索引](drawing-patterns.md)，不通读整套参考。

同一LDO的输入、稳压和输出电容归在同框，输入/输出电容靠对应侧；三脚、EN和多输出接法按真实型号处理。可见Value可用无歧义的短型号/容值，完整MPN保留在属性和方案，不删识别所需参数。

电路按功能组紧凑排列、相关器件成行。相邻电容、RC/按键、R+LED优先短线直接相连，标签用于跨框或较长网络；不靠标签把同一支路拆散。框随内容收紧、留白均匀，不为铺满页面拉开器件。先按真实引脚方向向外引线，再分配通道，避开其他引脚及地母线。

## 检查和修复

首版读整图确认页面、分区和接法；文字不清再读对应regionImages。集中记录具体位号/网络、问题和修改，一次修相关脚本后复核受影响区域、连接及整页范围。沿用未变区域结论，不重复渲染同版或写裁图/几何审计脚本。

联合检查返回 reviewPlan：issues 为有界问题摘要，issueCount/counts 是完整统计；omittedIssues>0 或 repairPlan.fullReportRequired=true 时定向读取 reportPath 的诊断再集中修复，不能只修前几项。repairPlan 分结构、空间决策、布局和读图确认阶段，近似重叠不当作已确认缺陷。mode=changed_regions 时局部图同时覆盖改动对象的新旧位置及遗留诊断；共享配置变化、无法确定范围或大范围修改自动回到 full。先一次读返回的相关图片、批量修复，不逐张裁图逐个改。unchanged 仅表示画面相同，不能代替视觉验收。最终模块提交前用 reviewMode:"full" 联合检查并读完整当前模块；正式整图仍须完整验收。版本比较记录位于工作区 work/modules/<模块>/visual-review.json，缺失或不可用时回退完整审图。

| 项目 | 必须满足 |
| --- | --- |
| 文件与格点 | 可构建和渲染；实际引脚、器件原点及连接点符合50mil，无未解析引脚 |
| 电路 | 实现确认方案；供电、地、电压域、极性、使能、复位、上拉、负载及跨模块接点无已知错漏 |
| 阅读 | 数值、位号、型号、脚号及接点可辨认；文字不压关键图形，不造成器件/网络归属误读 |
| 排列 | 功能组紧凑、主电源/信号顺读，相邻支路短线直连；无无故分散的标签孤岛和大片失衡留白 |
| 页面 | 框完整，器件/关键文字不越框或侵入其他模块、标题栏 |
| 工程 | 脚本、方案、正式图一致，本地库及必要属性完整，限制如实说明 |

简单项目首版达标即交付，否则集中修复再验证。增加迭代须指出具体阻塞对象、影响和改法；真实错误不受轮数限制。同一缺陷两次未解决，改用更宽区域、明确通道或显式字段位置，不反复微调同一偏移。

文字压脚号、数值遮挡、标签混叠均是交付缺陷，主 agent 必须关闭子任务遗留项。结构passed、默认字段零未决、文字检测零问题或readyForAssembly，都不等于视觉验收；检测不覆盖所有文字/图形/引脚关系。近似包围盒提示按当前图说明误报位置，不追求清零，不为纯装饰重建。电源最终问题以save().powerLayout为准，不追逐早先automatic诊断。

## 发布一次

验收后只替换固定project/内本设计生成文件及明确子页，保留库、其他文件和用户改动；子页使用相对路径。同步方案、已用任务状态和必要清理。仅库表/封装变化时重查现有候选，不重画。

最后调用 `render_kicad_module_preview({schematicPath:正式图路径,projectDir:正式工程目录,delivery:true})`；必须deliveryStatus:ready且overview有效。失败按failures/overviewError修复，保留已有工程和图片。正式概览是本轮最后一个工具操作，随后直接交付；之后若再调用工具须重新正式交付。ZIP只收集project内设计和本地库，脚本/来源另外链接。

默认不额外运行ERC或独立网表比对；用户要求时执行。预览、声明连接及交付卡片均不证明完整电气正确。
