# 平铺工程文件处理

仅在需要了解配置字段、复制后改名或使用 KiCad 手动编辑时读取此参考。

`edit_kicad_flat_schematic` 的 `create` 操作将已有单页图复制到设计根目录的 `schematic/`，生成同名 `.kicad_sch` 和 `.kicad_pro`。`targetDir` 是已存在的设计根目录，例如 `designs/ldo_ams1117`，不是其 `schematic/` 子目录；缺少子目录时由工具写入过程创建。输出名称必须未被占用，后续再编辑也需使用未占用的工程名或目录。

固定配置在 [project.kicad_pro](../templates/project.kicad_pro)，取自当前安装的 KiCad 10 工程模板，包含 `board`、`libraries`、`meta`、`net_settings` 等最低工程字段。工具将 `meta.filename` 更新为输出工程名，不复制来源工程的路径或 ERC 忽略项。不要自行查找其他工程配置，也不要用 `{}` 代替模板。模板目录由工具插件的 `flatTemplateDir` 配置指定；修改模板后重启 DSH。

工具生成新根 UUID，并更新保留符号实例中的工程名、根路径、引用编号和 unit，保留下载来源和嵌入符号内容。源图缓存必须与实例的 `lib_id` 唯一对应；编号后缀造成的名称差异由已有厂家缓存匹配规则在副本中对齐，不改引脚或图形，无法唯一对应仍报错。根据错误定位源模块或选择其他候选，不删除缓存来绕过问题。引脚连接使用匹配的缓存定义、实际 unit、旋转和镜像，无法确定坐标时不猜测。

新增符号后随工程交付工具生成的 `.kicad_sym` 和 `sym-lib-table`，使用返回的 libId；符号导入本身不生成可编辑的实例。单页副本不需要包成层次子页。手动改动时保持符号缓存、实例和相关库文件一致。
