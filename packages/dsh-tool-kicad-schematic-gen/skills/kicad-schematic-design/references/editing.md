# 修改脚本与工程文件

修改项目生成脚本并重新构建候选，不只改输出的KiCad文件；安装资源只读，保留sources原图、用户文件与未保存改动。

- 器件、参数、标签或连线：修改对应模块.mjs；删除器件时同步导线、标签和连接声明。引脚用真实pin，不猜坐标。
- 并行模块的位置/尺寸：由主 agent 改清单region；顺序旧脚本才改layout.mjs。局部替换及UTF-8要求见 [编程接口](programming.md#脚本编辑与编码)。
- 没有生成脚本的外部原图：保留来源，在脚本中用importModule适配；复杂修改用公开API重建所需模块，不用固定行号/全局正则修改KiCad文本。
- 复用导入由API处理UUID、位号、实例路径和缓存，见 [平铺复用](flat-reuse.md)。缓存无法唯一匹配时修来源，不删除缓存绕过。

方案变化先更新并读回版本。修改后模块检查、看受影响区域，主 agent 装配后验证受影响连接。发布到固定project/并保留本地符号、封装及库表；具体验收和正式概览见 [布局交付](layout-delivery.md)。
